# 6.1. The Penetration Testing Lifecycle
- 침투 테스트 단계 이해
- 각 단계 내에서 정보 수집 롤 배우기
- Active/Passive 정보 수집 차이

### 침투테스트 단계
	- Defining the Scope  범위 정의
	- Information Gathering  정보 수집
	- Vulnerability Detection  취약점 감지
	- Initial Foothold  초기 거점
	- Privilege Escalation  권한 승격
	- Lateral Movement  측면 운동
	- Reporting/Analysis  보고/분석
	- Lessons Learned/Remediation  교훈/교정

### reconnaissance (정찰)
	- 대상 조직의 인프라, 자산 및 인력 세부 정보 검색
	- Passive / Active
		- Passive: 대상의 정보를 검색하는 것을 목표로 함 (직접적 상호작용 없음)
		- Active: 인프라 직접 조사
	- 초기 정찰 후에도 지속적으로 데이터를 수집해야 하며, 거점을 확보하거나 시스템 간 측면 이동을 통해 대상의 공격 표면에 대한 지식 구축 필요

# 6.2. Passive Information Gathering

- 두가지 Passive 정보 수집 접근법 이해
- OSINT 알아보기
- 웹 서버 및 DNS 수동 정보 수집 이해

- Passive를 구성하는 요소에 대한 두 가지 맥락
	- 대상의 시스템이나 서버에 액세스 하지 않음.
	- 느슨하게 해석하면, 대상과 상호 작용은 하지만 일반 인터넷 사용자처럼만 가능함
	- 해당 모듈에서는 두번째 맥락으로 진행

- 패시브 정보 수집의 궁극적 목적
	- 공격 표면 명확하게 하거나 확장
	- 성공적인 피싱 캠페인 수행
	- 계전 손상으로 이어질 수 있는 비밀번호 추측 등과 같은 침투 테스트 단계 보완하는 정보 얻는 것

## 6.2.1. Whois enumeration

- Whois: TCP 포트 43을 사용하여 공용 데이터베이스와 통신하는 프로토콜. 데이터베이스를 쿼리하여 도메인 등록 기록을 검색함

- Whois 기록 내 포함되는 정보 요소
	- Name Server: DNS의 일부로 도메인 이름을 IP 주소로 변환하여 트래픽을 적절한 웹 서버로 전달함
	- Registrar: 도메인 이름이 등록된 회사
	- Registrant Contact: 도메인을 법적으로 소유한 개인 또는 조직. 조직 이메일, 전화번호가 포함됨
	- Administrative Contace: 도메인 소유권 및 액세스 관리 담당자
	- Technical Contace: DNS 레코드 또는 서버 통합과 같은 도메인의 기술 설정을 관리하는 개인 또는 팀
	- Creation and Expiration Dates: 도메인 첫 등록 날짜와 만료되도록 설정된 날짜
	- Domain Status: 도메인이 잠겨 있는지, 활성 상태인지, 전송 중인지 나타내는 플래그

- forward search: whois에 쿼리하여 도메인 소유자가 누구인지 찾는 것
- reverse whois: IP로 시작하지만 그 뒤에 엔티티를 자세히 알고 싶을 때 사용

- whois 도메인(ip주소) -h (whois 서비스 실행하는 호스트)

## 6.4.1. DNS enumeration
도메인 이름 > IP 주소 변환


- **NS**: Nameserver records contain the name of the authoritative servers hosting the DNS records for a domain.  
    NS: 네임서버 레코드에는 도메인의 DNS 레코드를 호스팅하는 권한 있는 서버의 이름이 포함됩니다.
- **A**: Also known as a host record, the "_a record_" contains the IPv4 address of a hostname (such as [www.megacorpone.com](http://www.megacorpone.com/)).  
    A: 호스트 레코드라고도 알려진 "레코드"에는 호스트 이름의 IPv4 주소(예: www.megacorpone.com)가 포함됩니다.
- **AAAA**: Also known as a quad A host record, the "_aaaa record_" contains the IPv6 address of a hostname (such as [www.megacorpone.com](http://www.megacorpone.com/)).  
    AAAA: 쿼드 A 호스트 레코드라고도 알려진 "aaaa 레코드"에는 호스트 이름의 IPv6 주소(예: www.megacorpone.com)가 포함됩니다.
- **MX**: Mail Exchange records contain the names of the servers responsible for handling email for the domain. A domain can contain multiple MX records.  
    MX: 메일 교환 레코드에는 도메인의 이메일 처리를 담당하는 서버의 이름이 포함됩니다. 도메인에는 여러 MX 레코드가 포함될 수 있습니다.
- **PTR**: Pointer Records are used in reverse lookup zones and can find the records associated with an IP address.  
    PTR: 포인터 레코드는 역방향 조회 영역에서 사용되며 IP 주소와 연결된 레코드를 찾을 수 있습니다.
- **CNAME**: Canonical Name Records are used to create aliases for other host records.  
    CNAME: 정식 이름 레코드는 다른 호스트 레코드에 대한 별칭을 만드는 데 사용됩니다.
- **TXT**: Text records can contain any arbitrary data and be used for various purposes, such as domain ownership verification.  
    TXT: 텍스트 레코드는 임의의 데이터를 포함할 수 있으며 도메인 소유권 확인과 같은 다양한 목적으로 사용될 수 있습니다.
